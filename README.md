**Breast Cancer Classification Project**



**Overview**

This project applies supervised machine learning classification techniques to predict whether a breast tumor is malignant or benign using the Breast Cancer Wisconsin Dataset.



**Dataset**

Source: Scikit-learn Breast Cancer Dataset



**Target Classes:**



0 = Malignant

1 = Benign

Models Used

Logistic Regression

Random Forest Classifier



**Evaluation Metrics**



Accuracy

Precision

Recall

F1-Score

Confusion Matrix

ROC Curve



**Results**



Logistic Regression

Accuracy: 95.61%

Precision: 94.59%

Recall: 98.59%

F1-Score: 96.55%

Random Forest

Accuracy: 96.49%

Precision: 95.89%

Recall: 98.59%

F1-Score: 97.22%

Random Forest achieved the best overall performance.
